# Release 1.0.0 - Versão Inicial de Produção

Esta branch consolida a primeira versão estável da aplicação para publicação em produção.

## O que contempla esta versão

- **Funcionalidades de base**: Estrutura do projeto, banco de dados e simulação de sessão (`chore/setup`, `chore/base-dados-sessao`).
- **Funcionalidades principais**: Listagem de salas (`SALA-1`), Agendamento (`SALA-2`), Minhas Reservas (`SALA-3`) e Painel Admin (`SALA-4`).
- **Documentação de versão**: Atualização do arquivo CHANGELOG informando todas as entregas presentes na versão 1.0.0.
